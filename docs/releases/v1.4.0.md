# QuietQuote v1.4.0

Windows: more markets, multiple floating price capsules. Public market data only; no API key or account required.

## 新功能 / What's new

- OKX 与 Binance，均支持现货和永续行情。Binance 合约为 USDⓈ-M 永续，不包含交割和币本位合约。
- 设置中可配置 1–8 个独立浮窗，每个窗口分别选择平台、市场类型、币种和计价单位。
- 每个浮窗分别保存位置，所有窗口共用外观及刷新间隔。
- 一个托盘图标；Ctrl+Alt+Q 统一隐藏／恢复全部窗口。
- 原有胶囊／圆形、七段数码管、毛玻璃、自动配色和中英文设置继续保留。
- 切换平台、市场、窗口时旧请求不会覆盖新选择；断线保留旧价并标记，不混用其他平台价格。

## Download / 下载

Download **QuietQuote-v1.4.0-windows.zip** under Assets, extract it and run **QuietQuote.exe**. The automatically generated Source code archives are for developers.

下载 Assets 中的 **QuietQuote-v1.4.0-windows.zip**，解压后运行 **QuietQuote.exe**。升级前从托盘退出旧版；将旧版 settings.json 复制到新版程序旁，可保留原有偏好和币对。

Set the window count in Settings → Market windows, configure each window and Save. Appearance and refresh settings apply to all windows.

Binance spot tickers do not provide a trade timestamp; the tooltip explicitly shows local receipt time. Availability depends on the user's network and region.

Windows 10/11 with .NET Framework 4.8. The executable is unsigned.

**macOS:** experimental source remains single-window and OKX-perpetual-only. The v1.4 multi-market features are Windows-only. No verified Mac binary is included in this release.
