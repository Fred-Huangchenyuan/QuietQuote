# QuietQuote v1.3.0

A compact Windows desktop ticker for OKX perpetual futures. No API key needed.

- Adjustable capsule/circle with seven-segment digits.
- Optional glass, adaptive light/dark themes, English/Chinese UI.
- Coin and quote-currency selection; refresh intervals from 1 to 3600 seconds.
- Connection and stale-data indicators, automatic retries.

Download **QuietQuote-v1.3.0-windows.zip**, extract, and run **QuietQuote.exe**. Recommended: Windows 10/11 with .NET Framework 4.8. Exit the old instance first. Your existing `settings.json` can be copied into the new folder.

`SHA256SUMS.txt` contains the archive checksum. This release is unsigned. Glass appearance depends on Windows composition settings; auto theme estimates nearby background brightness. See the README for compatibility limits.
