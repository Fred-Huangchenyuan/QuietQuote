# Changelog

## Unreleased macOS preview

- Added native Swift/AppKit/SwiftUI source, offline Swift tests and architecture-specific packaging.
- Added separate Apple Silicon and Intel GitHub Actions jobs.
- Not compiled or runtime-tested in the Windows preparation environment. Not a verified macOS release.
- Mac Auto theme follows system appearance; Windows-specific pixel sampling/global hotkey are not ported.

## 1.3.0 — 2026-11-06

First GitHub launch package, based on the locally tested 1.3 desktop application.

- Configurable capsule and circle shapes.
- Seven-segment numerals without an external font.
- Automatic, light and dark non-glass themes; Windows glass mode retained.
- English and Chinese UI, dynamic perpetual contract selection, adjustable refresh interval.
- Added versioned builds, offline tests, optional desktop/live tests, release packaging, checksums and Windows CI.

Earlier 1.0–1.2 iterations were local prototypes, not GitHub releases.
